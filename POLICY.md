## Klasyfikacja i kolejność pracy

```dsl
CONTRACT WORK_CLASSIFICATION = "governance/work-classification.dsl.json"

RULE P-WORK-001 TYPE REQUIRED
WHEN WORK_ITEM_CREATED_OR_IMPORTED
DO REQUIRE kind IN [BUG, FEATURE, SERVICE]
DO REQUIRE priority IN [P0, P1, P2, P3]
DO REQUIRE origin IN [regression, requested, health]

RULE P-WORK-002 TYPE REQUIRED
WHEN READY_WORK_ITEMS_ORDERED
DO APPLY_TOPOLOGICAL_DEPENDENCY_ORDER
DO ORDER_READY_ITEMS BY kind [BUG, FEATURE, SERVICE] THEN priority [P0, P1, P2, P3] THEN stableId
ASSERT DEPENDENCY_ORDER_PRECEDES_RANKING

RULE P-WORK-003 TYPE REQUIRED
WHEN CYCLOMATIC_COMPLEXITY_SIGNAL_CLASSIFIED
DO CLASSIFY BASELINE_TO_HEAD_INCREASE_OR_NEW_THRESHOLD_CROSSING AS BUG regression
DO CLASSIFY PRE_EXISTING_NOT_INCREASED_DEBT AS SERVICE health

RULE P-WORK-004 TYPE REQUIRED
WHEN WORK_CLASSIFICATION_REQUIRED
DO LOAD_AND_VALIDATE WORK_CLASSIFICATION
DO REJECT_UNMATCHED_OR_INVALID_CLASSIFICATION
FORBID USE_LLM_OUTPUT_AS_DETERMINISTIC_CLASSIFICATION_TRUST_ROOT
ASSERT LLM_CLASSIFICATION_IS_ADVISORY_ONLY
```
