## WORKBOARD

```dsl
RULE C-WORKBOARD-001
WHEN TASK_STEPS > 1 OR AGENT_REQUIRED
DO IDENTIFY TASK_OWNER AND TASK_ASSIGNEE
DO USE ACTOR_DIRECTORY MATCHING WORKBOARD_ACTOR_PATTERN
ASSERT HUMAN_AND_AI_ASSIGNMENTS_DISTINGUISHABLE

RULE C-WORKBOARD-002
WHEN WORKBOARD_USED
DO SEPARATE ASSIGNED_SCOPE FROM EXECUTION_REPORT
ASSERT TASK_FILE != WORKLOG_FILE

RULE C-WORKBOARD-003
WHEN ACTOR_DIRECTORY_CREATED
DO REQUIRE "tasks"
DO REQUIRE "prompts"
DO REQUIRE "worklogs"
ASSERT ACTOR_WORK_VISIBLE_IN_SINGLE_DIRECTORY

RULE C-WORKBOARD-004
WHEN WORKBOARD_STRUCTURE_OR_FORMAT_REQUIRED
DO FOLLOW WORKBOARD_REFERENCE
ASSERT DETAILED_FORMAT_NOT_DUPLICATED_IN_CONTRIBUTING
```

## STATE

```dsl
STATE START
STATE ANALYSIS
STATE PLAN
STATE TOOLS
STATE DELEGATION
STATE EDIT
STATE VALIDATION
STATE PUBLICATION
STATE DONE
STATE BLOCKED

TRANSITION START -> ANALYSIS
TRANSITION ANALYSIS -> PLAN
TRANSITION PLAN -> TOOLS
TRANSITION TOOLS -> DELEGATION
TRANSITION DELEGATION -> EDIT
TRANSITION EDIT -> VALIDATION
TRANSITION VALIDATION -> PUBLICATION
TRANSITION PUBLICATION -> DONE
TRANSITION ANY -> BLOCKED WHEN REQUIRED_EVIDENCE_MISSING
```

## PROCEDURA START

```dsl
RULE C-START-001
WHEN TASK_RECEIVED
DO READ_RELEVANT_FILES
DO RUN "git status --short"
ASSERT WORKTREE_STATE_CAPTURED
NEXT ANALYSIS

RULE C-START-002
WHEN TASK_SCOPE_NOT_CLEAR
DO LIMIT_SCOPE_TO_USER_REQUEST
ASSERT SCOPE_MINIMAL
NEXT ANALYSIS
```

## PROCEDURA ANALYSIS

```dsl
RULE C-ANALYSIS-001
WHEN CLAIM_OR_TOOL_OR_WORKFLOW_REFERENCED
DO VERIFY_IN_CURRENT_FILES_OR_COMMAND_OUTPUT
ASSERT UNVERIFIED_ITEMS_ARE_LABELLED
NEXT PLAN

RULE C-ANALYSIS-002
WHEN project.sh IS_RELEVANT
DO DISTINGUISH ACTIVE_COMMANDS FROM COMMENTED_COMMANDS
ASSERT COMMENTED_COMMANDS_NOT_USED
NEXT PLAN

RULE C-ANALYSIS-003
WHEN REPOSITORY_FEATURE_NOT_FOUND
DO MARK FEATURE AS UNVERIFIED
ASSERT FEATURE_NOT_PRESENTED_AS_AVAILABLE
NEXT PLAN
```

## PROCEDURA PLAN

```dsl
RULE C-PLAN-001
WHEN TASK_STEPS <= 1
DO KEEP_PLAN_INLINE
ASSERT TODO_NOT_REQUIRED
NEXT TOOLS

RULE C-PLAN-002
WHEN TASK_STEPS > 1
DO CREATE_OR_UPDATE "TODO.md"
DO CREATE_OR_UPDATE ASSIGNEE_TASK_FILE WHEN WORKBOARD_USED
DO RECORD SCOPE RISKS ACCEPTANCE_CRITERIA STATUS
ASSERT TODO_CONTAINS_PROJECT_LEVEL_WORK_TRACKING
ASSERT TASK_FILE_CONTAINS_ASSIGNED_SCOPE
NEXT TOOLS

RULE C-PLAN-003
WHEN CHANGE_RISK_HIGH
DO RECORD RISK_AND_CHECKS
ASSERT RISK_VISIBLE_BEFORE_EDIT
NEXT TOOLS

RULE C-PLAN-004
WHEN WORKBOARD_USED
DO CREATE_OR_UPDATE ASSIGNEE_WORKLOG
DO RECORD IMPLEMENTATION_PLAN
ASSERT IMPLEMENTATION_PLAN_DOES_NOT_REDEFINE_TASK_SCOPE
NEXT TOOLS
```

## PROCEDURA TOOLS

```dsl
RULE C-TOOLS-001
WHEN TOOL_REQUIRED
DO VERIFY TOOL_EXISTS AND INVOCATION_EXISTS
ASSERT TOOL_STATUS IN [VERIFIED, UNVERIFIED]
NEXT DELEGATION

RULE C-TOOLS-002
WHEN PACKAGE_INSTALLED AND COMMAND_NOT_INVOKED
DO SET TOOL_STATUS = INSTALL_ONLY
ASSERT TOOL_NOT_PRESENTED_AS_AVAILABLE
NEXT DELEGATION

RULE C-TOOLS-003
WHEN DOCUMENTATION_ONLY_CHANGE
DO SKIP "project.sh"
ASSERT INSTALL_OR_OVERWRITE_NOT_REQUIRED
NEXT DELEGATION
```

## PROCEDURA DELEGATION

```dsl
RULE C-DELEGATION-001
WHEN AGENT_REQUIRED
DO VERIFY AGENT_DEFINITION AND AGENT_INVOCATION
ASSERT AGENT_STATUS IN [VERIFIED, UNVERIFIED]
NEXT EDIT

RULE C-DELEGATION-002
WHEN AGENT_STATUS = UNVERIFIED
DO USE_LOCAL_WORKFLOW_OR_REPORT_BLOCKER
ASSERT UNVERIFIED_AGENT_NOT_USED
NEXT EDIT OR BLOCKED

RULE C-DELEGATION-003
WHEN AGENT_REQUIRED AND WORKBOARD_USED
DO REQUIRE ASSIGNED_TASK_FILE
DO RECORD MATERIAL_AGENT_INSTRUCTIONS
ASSERT AGENT_INSTRUCTIONS_REFERENCE_TASK
NEXT EDIT
```

## PROCEDURA EDIT

```dsl
RULE C-EDIT-001
WHEN TARGET_FILE_EXISTS
DO READ TARGET_FILE
DO MODIFY_ONLY_REQUESTED_SCOPE
ASSERT EXISTING_MEANING_PRESERVED
NEXT VALIDATION

RULE C-EDIT-002
WHEN TARGET_FILE_MISSING
DO VERIFY_PARENT_DIRECTORY
DO CREATE_ONLY_IF_REQUIRED_BY_TASK
ASSERT NEW_FILE_JUSTIFIED
NEXT VALIDATION

RULE C-EDIT-003
WHEN DOCUMENTATION_CHANGED
DO KEEP_TERMS_CONSISTENT
DO REMOVE_DUPLICATION
ASSERT DOCUMENTATION_SHORTER_OR_CLEARER
NEXT VALIDATION

RULE C-EDIT-004
WHEN WORKBOARD_USED
DO UPDATE ASSIGNEE_WORKLOG
DO RECORD ACTUAL_CHANGES
DO RECORD UNFINISHED_ITEMS
DO RECORD BLOCKERS
ASSERT EXECUTION_STATE_VISIBLE
NEXT VALIDATION
```

## PROCEDURA VALIDATION

```dsl
RULE C-VALIDATION-001
WHEN CHANGE_COMPLETE
DO REVIEW_DIFF
DO CHECK_FORMAT
DO CHECK_REFERENCES
DO CHECK_SECRETS
ASSERT CHANGE_REVIEWED
NEXT PUBLICATION

RULE C-VALIDATION-002
WHEN TESTS_EXIST_AND_RELEVANT
DO RUN_RELEVANT_TESTS
ASSERT TEST_RESULT_REPORTED
NEXT PUBLICATION

RULE C-VALIDATION-003
WHEN TESTS_NOT_FOUND_OR_NOT_RELEVANT
DO REPORT TESTS_NOT_RUN_WITH_REASON
ASSERT TEST_SUCCESS_NOT_CLAIMED
NEXT PUBLICATION

RULE C-VALIDATION-004
WHEN WORKBOARD_USED
DO COMPARE ASSIGNEE_TASK_FILE
DO COMPARE ASSIGNEE_WORKLOG
DO COMPARE CURRENT_DIFF
DO COMPARE TEST_RESULTS
DO RECORD ACCEPTANCE_CRITERIA_EVIDENCE
ASSERT COMPLETED_AND_UNFINISHED_SCOPE_VISIBLE
NEXT PUBLICATION
```

## PROCEDURA PUBLICATION

```dsl
RULE C-PUBLISH-001
WHEN USER_DID_NOT_REQUEST_COMMIT
DO SKIP COMMIT
DO SKIP PUSH
ASSERT GIT_HISTORY_UNCHANGED
NEXT DONE

RULE C-PUBLISH-002
WHEN USER_REQUESTS_COMMIT
DO REVIEW "git status --short"
DO REVIEW "git diff"
DO COMMIT_ATOMIC_CHANGE
ASSERT COMMIT_DESCRIBES_REASON
NEXT DONE

RULE C-PUBLISH-003
WHEN USER_REQUESTS_PUSH
DO PUSH_ONLY_AFTER_COMMIT
ASSERT PUSH_TARGET_EXPLICIT
NEXT DONE
```
