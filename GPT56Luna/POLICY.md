## MODULE M01 TYPES_EVIDENCE

```dsl
TYPE Path
TYPE File
TYPE Directory
TYPE Command
TYPE Tool
TYPE Agent
TYPE Claim
TYPE Change
TYPE Dependency

TYPE Commit

EVIDENCE DIRECTORY_EXISTS = PATH_EXISTS AND DIRECTORY_READ

EVIDENCE COMMAND_PASS = COMMAND_EXECUTED AND EXIT_CODE = 0

ASSERT TOOL.STATUS = UNVERIFIED
NEXT CONTINUE

RULE P003
WHEN COMMAND_COMMENTED = TRUE
DO SET COMMAND.STATUS = UNVERIFIED

ASSERT COMMAND.STATUS = UNVERIFIED
NEXT CONTINUE
```

## MODULE M14 TERMINATION

```dsl
DONE WHEN
  RESULT = PASS
  AND ALL(C001..C009) = TRUE

BLOCKED WHEN
  RESULT = BLOCKED
  OR MISSING_EVIDENCE
  OR SPECIALIST_UNAVAILABLE
  OR REQUIRED_SOURCE_MISSING

HUMAN_DECISION WHEN
  RESULT = HUMAN_DECISION
  OR USER_DECISION_REQUIRED
  OR DESTRUCTIVE_OPERATION_REQUESTED

REJECTED WHEN
  RESULT = REJECTED
  OR SAFETY_VIOLATION
  OR SECRET_DETECTED
  OR RULE_VIOLATION
```
